A documentation release. The code is 0.3.0's; what changed is each package's README, which is also its page on PyPI. Every README runs requirements, installation, usage, the reference sections, the demos, what changed and the licence, and every link in them is absolute.

## langchain-agensgraph 0.3.1

The README gains a requirements section and a demos section.

```bash
pip install langchain-agensgraph
```
OR
```bash
pip install "agensgraph-ai[langchain]"
```

- Requirements — Python 3.11 to 3.14, the driver, AgensGraph 2.17 or later with the `pgvector` and `meta` extensions — come first, with how to build the extensions under them.
- The five demos and the text2cypher eval have a section of their own.
- What is new in 0.3.0 sits before the compatibility table.
- The connection pool is described as the driver's.
